# Prompts pentru lab1

  * **Prompt:** *"Cerință de generare proiect C++ modular Tic-Tac-Toe conform rubricii (interfețe Listener și Painter, clasă Engine, fișiere .hpp, main.cpp, README.md)."*
  * **Rezultat:** A fost generată arhitectura modulară a jocului bazată pe dependency injection.
  * **Prompt:** *"trimite atunci codul"*
  * **Rezultat:** A fost livrat codul sursă complet divizat pe fișierele `Listener.hpp`, `Painter.hpp`, `Engine.hpp`, `ConsoleListener.hpp`, `ConsolePainter.hpp` și `main.cpp`.
  * **Prompt:** *"new item sau file?"*
  * **Rezultat:** Clarificare privind crearea corectă a fișierelor de tip *Header File (.hpp)* și *C++ File (.cpp)* prin Solution Explorer.
  * **Prompt:** *"dupa ce ii dau pull din visual studio, ce fac?"*
  * **Rezultat:** Pașii pentru verificarea schimbărilor locale și pregătirea pentru Push.
  * **Prompt:** *"daca nu apare chenarul?"*
  * **Rezultat:** Instrucțiuni pentru crearea manuală a unui Pull Request între ramura `lab01` și `main` pe GitHub.
  * **Prompt:** *"ce trebuie sa pun in readme"*
  * **Rezultat:** Structura de bază pentru `README.md` (Titlu, Descriere, Reguli).
  * **Prompt:** *"explica fiecare cod"*
  * **Rezultat:** Explicație detaliată linie cu linie a fiecărui fișier `.hpp` și `.cpp` pentru pregătirea susținerii laboratorului.
  * **Prompt:** *"am nevoie sa fac un file pentru prompturi"*
  * **Rezultat:** Structurarea fișierului de jurnalizare a prompturilor conform cerințelor din barem.
  * **Prompt:** *"cum aranjez in github lucrurile din satanga?"*
  * **Rezultat:** Instrucțiuni pentru editarea secțiunii *About*, adăugarea de tag-uri și setarea ramurii implicite (Default Branch).
  * **Prompt:** *"ce este llm?"*
  * **Rezultat:** Definiția teoretică a unui Large Language Model și rolul său în contextul sarcinilor de laborator.
